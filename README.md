# 砖写北京 · Brick Beijing

> **体素（voxel）方块风格 + GTA 城市漫游 + 宝可梦拍照收集** 的北京城市观光模拟器
> 无需出门，在浏览器里逛北京：自由行走、探索景点、拍照打卡、收集图鉴、体验京味昼夜与市井烟火。

基于 **Vue 3 + Three.js (WebGL)** 实现，按 [PRD.md](./PRD.md) 产品需求文档开发，纯前端运行、无需服务器。
地标全部由 **Builder 方块 API 程序化建模**（`box / prism / roof / beam / sign`），**零模型文件、零图片纹理**，资产即代码。

---

## ✨ 核心特色

- 🏛️ **还原北京中轴格局** — 真实经纬度投影（现实 1km ≈ 游戏 200 格），8 个城区 + 护城河/什刹海/昆明湖水系 + 景山/万寿山/香山方块山体
- 📷 **摄影收集玩法** — 自由机位 + 6 种京味滤镜 + 自动识别景点，拍满图鉴做"北京旅行家"
- 🛗 **可登临的地标** — 中国尊 226m 天空观景台、佛香阁、奥林匹克塔、中央电视塔观景球、钟楼，以及**能真正走上去的八达岭长城马道**
- 🚇 **城市生活模拟** — 观光巴士、18 站地铁传送、昆明湖游船、路人 NPC 京片子对白、老字号买烤鸭
- 🗣️ **NPC 语音朗读** — Web Speech API 按身份变调（小孩尖亮 / 大爷浑厚 / 姑娘清亮），文化图鉴带讲解播报，无需音频文件
- 🌗 **昼夜与天气** — 晴/阴/雨/台风随机切换（含雷暴闪电），20 分钟一天的光照流转，夜晚窗灯、灯笼与水立方气泡

## 🗺️ 已实现内容

### 世界地图

- 真实经纬度投影，1km ≈ 200 格，核心区外按比例压缩；投影原点 = 天安门
- 覆盖 8 个区：东城（中轴核心·胡同市井）/ 西城（皇城园林·坛庙）/ 朝阳（现代 CBD·奥运区）/ 海淀（皇家园林·学府）/ 丰台 / 石景山 / 昌平 / 延庆（八达岭长城）
- 水系：护城河、什刹海（西海→后海→前海）、北海、长河（皇家御河）、昆明湖、永定河、通惠河
- 主干道路网与桥梁，景山 / 什刹海 / 颐和园等高地形的方块山体

### 景点（18 个，S/A 两级 + 远景 LOD 简模）

| 级别 | 代表景点 |
| --- | --- |
| S | **故宫**（午门—金水桥—三大殿—后三宫—御花园、角楼、护城河）、**天坛**（祈年殿三重蓝檐、皇穹宇、回音壁、圜丘天心石）、**前门·大栅栏**（城楼/箭楼/瓮城 + 老字号街区）、**八达岭长城**（沿燕山山脊的可行走马道、四座敌楼、好汉坡）、**中国尊**（528m 收腰花樽 + 226m 玻璃观景台）、**央视总部**（162m 悬挑闭环）、**鸟巢**（编织钢梁马鞍形）、**水立方**（三千余个 ETFE 蓝色气泡，夜景内透光）、**天安门** |
| A | 天安门广场（纪念碑/国旗杆）、**景山万春亭**（俯瞰中轴官方机位）、钟鼓楼、颐和园（长廊/十七孔桥/石舫/佛香阁）、圆明园大水法遗址、香山香炉峰、奥林匹克塔、国贸天际线、中央电视塔 |

> 6 个出生点：天安门广场 / 王府井 / 什刹海 / 奥林匹克公园 / 颐和园 / 国贸 CBD

### 玩法系统

- **玩家角色**：方块小人，男/女、肤色/发型/上衣/裤子/鞋子/眼镜/长裙自定义，支持上传 **64×64 标准体素皮肤**（MC 皮肤格式通用）；WASD + 鼠标，奔跑跳跃，第一/第三人称切换
- **摄影系统**（`C` 键）：第一/第三人称/自拍视角、自由机位与变焦、6 种滤镜（原图 / **京味·复古胶片** / **夜京城·霓虹** / 清新 / 黑白 / 像素），自动识别画面中的景点并点亮图鉴，照片存入相册（IndexedDB，可下载 / 删除）
- **NPC 路人**：上班族 / 学生 / 大爷大妈 / 游客 / 小孩 / 老北京六类身份，随机姓氏与外观，会走路、聊天、拍照、买东西、等公交；**按 E 搭话即用京片子语音朗读**（"您吃了没？没吃家里凑一口去"），台词随天气与所在景点变化
- **城市交通**：观光巴士 1 路（西单 ⇄ 天安门 ⇄ 王府井 ⇄ 前门 ⇄ 国贸，¥2 一票真的坐上去开）、18 个地铁站 / 11 条真实线路快速传送、**昆明湖游船**（¥60，途经十七孔桥·南湖岛·石舫，甲板上可走动拍照）、城市车流
- **登临与彩蛋**：中国尊 / 佛香阁 / 奥林匹克塔 / 中央电视塔观光电梯，钟鼓楼登楼，**登上长城马道**；圜丘**天心石**说话有回音、贴**回音壁**耳语隔墙可闻
- **天气与时间**：晴 / 阴 / 雨 / 台风自动切换，`T` 键跳到下一个时段；夜晚窗灯、灯笼、霓虹与水体反射
- **收集与任务**：三套图鉴（建筑 / 美食 / 文化）+ 纪念品背包；**新手任务「北京初体验」**（拍故宫 → 访天坛 → 尝京味小吃 → 登景山）；**7 条主题任务**（中轴经典线 / 皇家园林线 / 现代北京线 / 长城线 / 胡同市井 / 吃在北京 / 京味文化达人）；**10 条每日任务**（按日期刷新）
- **京味内容库**：10 种美食（挂炉烤鸭、铜锅涮羊肉、炸酱面、炒肝、卤煮火烧、豆汁焦圈、艾窝窝、驴打滚、冰糖葫芦、宫廷酸奶）、10 项文化（京剧、胡同、四合院、中轴线、景泰蓝、兔儿爷、鸽哨、庙会、挂炉烤鸭技艺、京韵大鼓与相声）、16 件纪念品、12 家老字号店铺
- **性能优化**：景点按距离流式加载/卸载（`loadR` 分区控制）+ 远景 LOD 简模、Builder 同材质方块合并网格、InstancedMesh 实例化、高/中/低三档画质与阴影/反射开关

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/<你的用户名>/brick-beijing.git
cd brick-beijing

# 安装依赖
npm install

# 本地开发（默认 http://localhost:5173）
npm run dev

# 生产构建（输出到 dist/，可直接静态部署）
npm run build

# 本地预览构建产物
npm run preview
```

> 构建使用相对路径（`base: './'`），`dist/` 可直接部署到任意静态托管（GitHub Pages、Vercel、Nginx 等）。
> 需支持 WebGL2 的桌面浏览器（Chrome / Edge / Firefox / Safari 近两年版本）。

## 🎮 操作说明

### PC 端（主要目标平台）

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| `Shift` / `空格` | 奔跑 / 跳跃 |
| 鼠标 | 旋转视角（点击画面锁定鼠标，右键拖拽亦可） |
| 滚轮 | 第三人称镜头距离 / 摄影变焦 |
| `V` | 切换第一/第三人称（摄影模式下切换机位视角） |
| `C` | 进入/退出摄影模式 |
| `F` / `Enter` / 点击快门 | 按下快门 |
| `1` – `6` | 摄影滤镜 |
| `E` | 交互 / 对话 / 乘车 / 登船 / 登城 |
| `T` | 时间快进（跳到下一时段） |
| `M` / `B` / `P` / `N` / `J` | 地图 / 背包 / 相册 / 图鉴 / 任务 |
| `H` / `Esc` | 帮助 / 关闭面板 |

### 移动端（实验性，PRD 中列入 V2）

- 左侧**虚拟摇杆**移动，右半屏滑动旋转视角
- 右下按钮：跳 / 跑 / 交互 `E` / 摄影 📷 / 视角 👁
- **竖屏进入游戏会提示"请横屏操作"**（可选择仍要竖屏继续），旋转手机后自动进入横屏布局
- 画质与 NPC 密度建议调低档，性能明显更好

## 🛠️ 技术栈

- **框架**：Vue 3（Composition API）
- **3D 渲染**：Three.js 0.170 / WebGL（ACES 色调映射、PCFSoft 阴影）
- **建模**：程序化代码建模（Builder 方块 API），无外部模型/图片资源
- **音频**：Web Speech API（NPC 语音）+ WebAudio 合成音效（打卡提示音），无音频文件
- **构建**：Vite 6
- **存储**：localStorage（存档/图鉴/任务）+ IndexedDB（照片）
- **风格**：体素（voxel）方块美学 + 京味调色板（宫墙红 `#8C1F28` / 琉璃黄 `#C8A24A` / 琉璃蓝 `#2A5CAA` / 金顶 `#D4AF37` / 汉白玉 `#EDEAE0`）
